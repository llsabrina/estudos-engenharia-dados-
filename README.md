# ✨  Estudos de Engenharia de Dados

Processo para computar, analisar e salvar dados de alunos matriculados, 
em rematrícula e cancelados, assim como a tabela de pagamentos. 
Os dois DataFrames foram mesclados para ter a documentação completa 
do estudante na instituição. O resultado é salvo em CSV ao final.

## 💖 Tecnologias
- 🐍 Python 3.13
- 🐼 Pandas

## Arquivos
- `aula01_pandas_basico.py` — criação de DataFrames, filtros, ordenação e merge básico
- `aula02_etl.py` — leitura de CSVs, transformações e exportação do resultado
- `aula03_funcoes.py` — pipeline ETL organizado em funções reutilizáveis

## 🚀 Como rodar
1. 📦 Instale o pandas: `pip install pandas`
2. 💅 Execute: `python aula03_funcoes.py`
